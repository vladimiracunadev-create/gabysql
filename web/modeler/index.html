Importar de gabysql

El modeler hace GET /tables?db=<db> y reconstruye entidades, columnas, constraints e índices con la información que devuelve /schema. Necesita CORS habilitado en el server (lo está desde gabysql VERSION 33). Si tu server requiere autenticación cookie-based, pasá un Bearer token.

Nueva VIEW

El modeler emite CREATE VIEW <name> AS <cuerpo>;. La validación sintáctica del SELECT corre del lado del motor.

Nueva POLICY (RLS)

Emite CREATE POLICY <name> ON <table> FOR <action> [TO <role>] [USING (...)] [WITH CHECK (...)];. Al menos uno de USING / WITH CHECK requerido.

Nuevo objeto de seguridad
